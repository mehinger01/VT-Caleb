# VT-Caleb

Interactive tutoring workspace for Caleb's study-skills and executive-function coaching.

## First-session focus

- Strength-based executive-function intake
- School information-flow diagnostic
- Live note-taking challenge
- Four-Box Note Method
- End-of-Class 4 routine
- Field-test commitment
- Tutor and parent summary generator

## Technical notes

The site is a dependency-free single-page application contained in `index.html`. It uses browser `localStorage` to preserve session work on the current device and includes responsive and print-friendly layouts.

## Deployment

The repository can be deployed directly through GitHub Pages, Vercel, Netlify, or another static host. No build command is required.
